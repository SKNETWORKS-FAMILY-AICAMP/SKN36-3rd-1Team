## 공식 근거와 채점 기준

- 시행령 제6조 제1항은 해양수산부장관이 정해 고시한 최소 조업일수 이상과 고시 의무 이행을 지급요건으로 둔다. 확인한 시행령 판본의 시행일은 2025-07-08이다. [시행령 제6조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=166297)
- 해양수산부고시 제2024-6호 제2조 별표와 릴리스의 공식 별표 전사를 대조했다. 해당 연도 최소 60일이며 TAC 적용 어종을 주로 어획하는 어선은 30일 이상도 인정된다. 2026년 비TAC 경계 문항의 기준은 59일 미충족, 60·61일 충족이다. 법령센터 목록은 2024-01-17 시행, 해수부 게시문은 2024-01-18로 표기한다. [고시 목록](https://www.law.go.kr/conAdmrulByLsPop.do?lsiSeq=272651) · [해수부 개정 게시문](https://www.mof.go.kr/doc/ko/selectDoc.do?bbsSeq=35&docSeq=55020&menuSeq=886)
- 시행규칙 제20조 별표 2(2023-03-30 개정) 제2호 마목은 수산자원보호 직불금 준수의무 미이행의 지급제한을 규정한다. 10·20·40%는 별표에서 열거한 별도 의무 위반에 적용하며, 조업일수 60일 이하를 그 비율과 직접 연결하지 않는다. [시행규칙 별표 2](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=126767229&gubun=)
- 정부24 원문은 직접 조회가 되지 않아 보존본 `DOC_GOV_006`과 #97의 원문 대조 기록을 사용했다. 보존본은 60일 이상 요건과 60일 이하 감액 문구를 함께 싣고 있다. 문구를 소개할 때 60이 두 표현에 모두 포함됨을 설명하고, 법령이 정한 최소 조업일수와 별도의 지급제한을 구분하는지를 본다. [정부24 출처](https://plus.gov.kr/portal/benefitV2/benefitTotalSrvcList/benefitSrvcDtl?svcSeq=798789&bnefType=all&svcId=119200000194) · [#97 법령 대조](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN36-3rd-1Team/issues/97#issuecomment-7033053262)

질문에 필요한 핵심 결론과 근거가 맞으면 통과다. 핵심 결론이 맞고 출처 또는 설명에 수정할 부분이 있으면 부분 통과다. 포함 관계를 틀리거나 근거가 뒷받침하지 않는 개인 지급제한을 단정하면 실패다. 단순 기준 질문에서는 지급제한과 최종 자격의 생략을 허용한다.

## 실제 실행 환경과 진단 한계

- 이전 JSON에서 요청을 그대로 가져와 같은 순서로 기존 FastAPI `127.0.0.1:18200/api/ask`에 5건을 보냈다. 모두 HTTP 200, `answered`, `is_sample=false`이며 정책 `POL_GOV_006`의 Checker 자격 조건은 모두 `needs_check`였다.
- 기존 기동 기록과 대응 작업 디렉터리는 dev `6b4fdc96b154b47194d0460c19be23f70d779546`를 가리킨다. 대응 디렉터리의 추적 파일은 변경 표시가 없었으며, API가 실행 커밋을 직접 반환하지는 않는다. 목록은 릴리스 파일 기준 정책 249건과 manifest `b31307223f7334ffb7588d55670318d07d36e3fc18a78f62e8c961fdad04f3da`를 반환했다.
- 공개 API로는 상담이 실제 연결한 Neo4j·Qdrant, 검색 프로필, 공급자 모델 ID를 확인할 수 없다. `gpt-5.4-mini`는 기존 서버 코드 기본값이다. 최종 인용에 고시가 나온 사실로 상담 DB의 배포 버전을 확정할 수 없다.
- 이번에는 원래 60일 문항을 포함해 5건 모두 최종 인용에 고시 `DOC_GOV_006_MOF_NOTICE_2024`가 있었다. 이전 실행에서 고시가 최종 인용에 없었던 이유는 검색 후보·채택 청크·생성 직후 출력이 없어 미확정이다. 새 응답의 60일 오류는 고시가 최종 인용에 포함돼도 발생했다. 공개 응답으로 확인할 수 있는 최초 지점은 답변 본문이며 내부 생성·후처리 경계는 미확정이다.
- 별도 자동 테스트와 브라우저 검증은 미실행이다. 후속 평가에서는 연결된 DB·실제 모델 ID와 검색 후보 및 채택 청크가 함께 남는 환경에서 두 60일 문항과 59일 문항을 우선 비교한다. 운영 모델 선정은 팀 리뷰 사항이다.
