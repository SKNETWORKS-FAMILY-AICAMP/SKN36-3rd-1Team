# #97·#82 RQ031 실서비스 사전 평가

2026-11-25 KST · 정책 `POL_GOV_006` · 원문 재현 2건, 조업일수 경계값 3건

**실제 상담 요청 5건 모두 HTTP 200 / `answered` / `is_sample=false`. 의미 검수는 1건 통과, 4건 실패.** 정책 카드의 자격 조건은 5건 모두 `needs_check`였다.

## 환경과 재현 조건

- 기존 R3D 검증에 사용된 로컬 FastAPI `127.0.0.1:18200`의 `POST /api/ask`를 사용했다. 기존 기동 기록 기준 코드는 dev `6b4fdc96b154b47194d0460c19be23f70d779546`이며 대응 작업 디렉터리의 추적 파일에 변경이 없음을 확인했다. API가 커밋을 직접 반환하는 기능은 없다. 현재 주 작업 디렉터리의 HEAD `d01c632`에서 서버를 새로 띄우지 않았다.
- `/health`는 `ready=true`. `/api/policies`는 릴리스 파일 기준 249건, `1.4.0-candidate`, manifest `b31307223f7334ffb7588d55670318d07d36e3fc18a78f62e8c961fdad04f3da`를 반환했다. R3D 컨테이너와 Qdrant·Bolt 포트가 열려 있음도 확인했다. 다만 서버 환경 파일의 DB 포트가 R3D 포트와 달라 기동 시 환경 변수의 실제 적용값은 확인하지 못했다. 상담 응답에 새 고시 문서가 나타났으며, 상담이 연결한 개별 DB와 검색 프로필은 별도 추적으로 확인해야 한다.
- 해당 코드의 기본 모델은 `gpt-5.4-mini`다. Uvicorn 기동 옵션이 가리키는 환경 파일의 `LLM_MODEL`은 비어 있었다. 상속된 환경 변수와 공급자 응답의 모델 ID는 API에서 확인할 수 없어 **mini 기본값 기준 실서비스 결과**로 기록한다. 특정 모델로 확인된 비교 표본으로 집계하기 전 모델 ID 확인이 필요하다.
- PR #92의 r2 평가와 동일하게 개인정보·대화 이력·선택 정책 없이 각 문항을 별도로 요청했다. 최초에는 프로필 객체를 비워 5건 모두 422였다. 공개 스키마에 맞춰 `age=null`, `region=""`, `income=null`을 제공한 뒤 평가했다.

## 공식 근거와 평가 기준

- 시행령 제6조는 고시가 정한 최소 조업일수 이상 조업하고 고시 의무를 이행한 경우 지급하도록 정한다. [국가법령정보센터 시행령 제6조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=166297)
- 해양수산부고시 제2024-6호 제2조 별표는 **해당 연도 60일 이상**을 최소 조업일수로 정한다. 총허용어획량(TAC) 적용 어종을 주로 어획하는 어선은 **30일 이상**도 인정한다. 국가법령정보센터 위임행정규칙 목록과 릴리스 메타데이터의 시행일은 2024-01-17이며, 해양수산부 게시문은 2024-01-18로 표기한다. 릴리스의 공식 별표 전사와 보존 청크 `DOC_GOV_006_MOF_NOTICE_2024_P01_C01`을 대조했다. [국가법령정보센터 고시 목록](https://www.law.go.kr/conAdmrulByLsPop.do?lsiSeq=272651) · [해양수산부 고시 게시문](https://www.mof.go.kr/doc/ko/selectDoc.do?bbsSeq=35&docSeq=55020&menuSeq=886) · [해양수산부 기준 안내](https://www.mof.go.kr/doc/ko/selectDoc.do?bbsSeq=10&docSeq=54612&menuSeq=971)
- 정부24의 60일 이하·10/20/40% 문구는 보존된 원문 인용이다. 시행규칙 제20조 별표 2의 지급제한과 고시의 조업일수 준수 기준을 구분한다. 정부24 문구를 설명할 경우 60이 이하에 포함된다는 점과 상위 근거와의 차이를 밝혀야 한다. 고시를 확보하지 못한 응답에는 충돌 안내와 유보를 기대하며, 최신 근거 반영 여부는 별도로 평가한다. [시행규칙 별표 2](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=126767229&gubun=) · [정부24 정책 페이지](https://plus.gov.kr/portal/benefitV2/benefitTotalSrvcList/benefitSrvcDtl?svcSeq=798789&bnefType=all&svcId=119200000194)

## 실패 지점과 남은 검증

- 원래 정확히 60일 문항은 최종 인용에 고시가 없다. API 응답에는 검색 후보나 채택 문맥이 없으므로 검색 누락, 문맥 선정, Generator 인용 누락 중 최초 지점은 미확정이다.
- 경계값 세 건은 최종 답변이 고시까지 인용했다. 공개 응답에서 확인되는 불일치 지점은 Generator를 거친 답변의 출처 해석과 60일 포함 관계다. 생성 직후 원문과 후처리 로그가 없어 내부 최초 지점은 미확정이다. API의 Checker 조건에 해당 오류는 나타나지 않았다.
- 답변의 최소 조업일수 결론은 경계값 세 건 모두 공식 근거와 일치했다. 지급제한 설명을 포함한 전체 검수에서는 세 건 모두 실패했다. 후속 평가 전에 실행 모델과 Neo4j·Qdrant 연결을 확인하고, 검색 후보·채택 청크·생성 전후의 출처를 남겨 동일 다섯 문항을 다시 비교한다.
- 이번 검증은 이슈·기존 증빙 대조, 공식 근거 및 릴리스 확인, 실제 API 5건, 응답별 의미 검수로 수행했다. 별도 자동 테스트 및 브라우저 검증은 미실행이다. #82 운영 모델 확정은 팀 리뷰 사항이다.
