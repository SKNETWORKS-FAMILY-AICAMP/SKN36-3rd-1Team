## 2. 문제 정의

기존 정적 품질 플래그는 v1.3.2 데이터셋을 대상으로 생성되었으며, v1.4.0 데이터셋에서는 적용되지 않았다.

기존 조사에서는 판정 보호 대상 100개 정책 중 63개는 그래프 기반 전체 보류가 적용되고 있었으나, 나머지 37개에는 필요한 정적 판정 보호가 적용되지 않는 문제가 확인되었다.

이후 정책 데이터 및 그래프 교정이 진행되었으므로 기존 플래그를 그대로 재사용하지 않고 최신 데이터셋을 대상으로 의미 점검을 다시 수행하였다.

### 3.2. S10 혼인·자녀 조건 탐지 개선

혼인 또는 자녀 관련 그래프 조건이 존재한다는 이유만으로 전체 요건이 충분히 모델링되었다고 판단하지 않도록 탐지 규칙을 개선하였다.

측면별 분류:

- unmodeled: 관련 조건 미모델링 의심

- review: 추가 검토 필요
- consistent: 자동 점검 범위에서 일치
- no_text: 관련 원문 표현 미탐지

S10 규칙 식별자: `S10_v2_unmodeled_incomplete_review`

최초 점검 후보 83개에서 최종 100개로 증가하였다. 기존 후보는 제거되지 않았으며 17개 정책이 추가되었다.

### 2. S10 복합 자녀 연령 조건 판정 개선

#### 문제 재현

기존 S10 v2에서는 원문 자녀 연령 조건 집합이 그래프 연령 조건 집합의 부분집합이면 `consistent`로 분류하였다.

이로 인해 원문에 없는 추가 연령 조건이 그래프에 존재하더라도 보호 대상에서 제외될 수 있었다.

| 원문 조건 | 그래프 조건 | 기존 결과 | 수정 후 |
|---|---|---|---|
| LT 24개월 | LT 24개월 | consistent | consistent |
| LT 24개월 | LT 24개월 + BETWEEN 36~60개월 | consistent | review |
| LT 24개월 + BETWEEN 36~60개월 | LT 24개월 | review | review |
| LT 24개월 + BETWEEN 36~60개월 | LTE 24개월 + BETWEEN 36~60개월 | review | review |
| LT 24개월 + BETWEEN 36~60개월 | 동일한 복수 조건 | consistent | review |

#### 구현 변경

`child_age_check()`를 추가하여 자녀 연령 비교 결과를 다음과 같이 구분하였다.

- `single_exact`: 단일 연령 조건의 완전 일치
- `multiple_conditions`: 서로 다른 복수 연령 조건의 집합 일치
- `mismatch`: 원문과 그래프 연령 조건 집합 불일치
- `no_text_age`: 원문에서 비교 가능한 연령 조건을 추출하지 못함

기존 세부 요건 누락 및 중복 검토 분류의 우선순위를 유지하면서 `single_exact`인 경우에만 `consistent` 분류를 허용하였다.

동일한 연령 표현의 반복은 집합으로 중복 제거한다. 서로 다른 복수 연령 조건은 AND/OR 논리 동등성을 확인하지 못하므로 보수적으로 `review` 처리한다.

규칙 식별자를 `S10_v2_unmodeled_incomplete_review`에서 `S10_v3_single_exact_child_age`로 변경하였다.

의미 점검 스크립트와 정적 플래그 생성기의 규칙 식별자를 일치시키고, 기존 v2 보고서를 신규 플래그 생성에 사용하는 경우 거부하도록 하였다.

### 5. Issue #40 UNKNOWN 부분 판정 보존

실제 검색 결과의 조건 트리와 `scoped_income_quality_attributes()`를 사용하여 신규 정적 플래그가 기존 UNKNOWN 부분 판정에 미치는 영향을 검증하였다.

|---|---|---|
| POL_GOV_039 | income, region | income, region, children, employment |
| POL_GOV_042 | income, region | income, region, children |

POL_GOV_042에 대해 다음 사용자 프로필을 검증하였다.

### 8. 검증 범위 및 남은 한계

- S10은 정규식 기반 의미 점검이며 실제 정책 자격 요건의 완전한 검증이나 공식 원문 재검증을 의미하지 않는다.
- 복수 자녀 연령 조건의 AND/OR 논리 동등성은 검증하지 않고 보수적으로 보호한다.
- 런타임 플래그 로더는 S10 규칙 식별자까지 강제 검증하지 않는다. 이번 변경에서는 코드·보고서·플래그를 함께 갱신하여 버전 불일치를 방지한다.
- 적용군·대조군 비교는 정적 경고만 제거한 테스트용 대조군을 사용한 검증이다.
- 정책 ID 필터를 사용하는 실제 검색 검증으로, 전체 검색 품질 평가와는 구분된다.
- DB 전후 건수 유지 여부를 확인하였으나 이번 Smoke에서 전체 벡터 및 그래프 속성의 불변성을 다시 검증한 것은 아니다.
- 로컬 HTTP Qdrant 연결에 따른 API Key 관련 경고 1건이 발생하였다.
- 최신 dev와의 병합 이후 통합 동작은 별도 확인이 필요하다.
- Generator·API·React 전체 서비스 E2E는 Issue #122에서 진행한다.
