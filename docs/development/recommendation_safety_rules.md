# SSOK — 정책 추천 및 필터링 엔진 안전장치 규칙 명세서 (recommendation_safety_rules.md)

> **기준일시:** 2026-11-05 (KST)  
> **수신 담당:** 검색/추천 엔진 개발자, LLM 프롬프트 엔지니어, GraphRAG 파이프라인 담당자  
> **목적:** 불명확하거나 누락된 자격 조건에 대해 추천 엔진이 자의적으로 '적격(Eligible)' 확정 처리를 하지 않도록 하는 안전장치 규정

---

## 1. 정책 추천 4대 필수 안전장치 (Safety Guardrails)

추천 엔진은 사용자 프로필(연령, 소득, 혼인, 취업, 지역 등)과 정책 자격 조건을 매칭할 때 다음 4대 원칙을 **예외 없이 준수**해야 합니다.

### [규칙 1] 연령 조건 불명확 시 '적격 확정' 절대 금지
- **대상 데이터:**
  - `requirements.age_review_needed == true`
  - `requirements.min_age == null and requirements.max_age == null and requirements.age_limit != false`
  - 원문이 0~0세로 표기되어 정규화된 정책 (28건)
- **추천 엔진 처리 지침:**
  - 사용자의 나이와 무관하게 해당 정책을 "신청 자격 적격"으로 확정 판정하지 않는다.
  - 검색 결과에는 포함하되, 상태 레이블을 `[추가 확인 필요: 연령요건 공고문 참조]`로 표시한다.
  - LLM 프롬프트에 `연령 요건이 공공데이터 원천에 명확히 기재되지 않았으므로 공식 공고문 원문 확인이 필수입니다`라는 주의 문구를 강제 주입한다.

### [규칙 2] 소득 기준 확인 불가 시 '적격 확정' 절대 금지
- **대상 데이터:**
  - `income_level == '소득무관/미확인'`이면서 공고문 본문에 '소득' 단어가 언급된 정책
  - `requirements.income_condition_label == '미등록코드'` 또는 `income_max_amount == 0`인 정책
- **추천 엔진 처리 지침:**
  - 사용자가 소득 정보를 입력했더라도 소득 적격으로 단정하지 않는다.
  - "소득 기준 충족 여부는 주관 기관 심사 필요" 상태로 서빙한다.

### [규칙 3] 참여 제한(제외 대상) 미검증 시 적격 확정 금지
- **대상 데이터:**
  - `requirements.excluded_participants` (`ptcpPrpTrgtCn`) 필드가 존재하는 모든 정책
  - 예: "기존 타 부처 유사 지원사업 수혜자 제외", "공무원 및 공공기관 재직자 제외"
- **추천 엔진 처리 지침:**
  - 사용자가 기본 자격(나이, 지역)을 만족하더라도 `중복수혜 배제` 조건이 남아있음을 명시한다.
  - UI 상에 `중복 수혜 제한 대상 여부를 확인하세요` 태그를 부착한다.

### [규칙 4] 정책 최신성 및 신청 기한 확인
- **대상 데이터:**
  - `lastMdfcnDt`가 1년 이상 경과했거나 `application_period`에 특정 과거 연도가 명시된 정책
- **추천 엔진 처리 지침:**
  - `reception_status`가 'active'이더라도 `[최신 공고 갱신 여부 확인 필요]` 플래그를 부착한다.
  - `official_apply_url` 또는 `source_url` 링크를 사용자에게 함께 제공하여 실시간 접수 여부를 유도한다.

## 2. 매칭 판정 3단계 상태 코드 (Recommendation Status Codes)

추천 엔진은 검색 결과의 각 정책 카드에 다음 3가지 중 하나의 판정 상태를 반환해야 합니다.

| 상태 코드 | 명칭 | 조건 | UI 및 LLM 처리 규칙 |
|---|---|---|---|
| **`CONFIRMED_ELIGIBLE`** | **신청 자격 부합** | 연령, 소득, 지역, 대상군이 모두 공식 검증 완료되고 사용자와 100% 일치 | "회원님의 조건에 부합하는 정책입니다" 강조 표시 |
| **`REVIEW_REQUIRED`** | **조건 확인 필요** | 연령 누락, 소득 상세 미확인, 0~0세 이상치 등 검토 플래그 존재 | "조건 확인 필요: 공고문 원문 대조가 필요합니다" 경고 표시 |
| **`INELIGIBLE`** | **신청 불가** | 연령 상·하한 미달/초과, 지역 불일치, 명백한 배제 대상 | 기본 목록에서 제외 (단, '유사 정책 보기' 요청 시 사유와 함께 노출) |

## 3. GraphRAG LLM 프롬프트 강제 가이드라인

답변 생성 LLM(Gemini / GPT / Claude 등)은 정책 안내 시 아래 시스템 프롬프트를 준수해야 합니다.

```markdown
당신은 대한민국 정부 정책 추천 AI 비서 SSOK입니다.
답변 작성 시 반드시 아래 규칙을 준수하세요:
1. 근거 없는 지원 조건, 금액, 서류를 절대 지어내지 마십시오.
2. 정책 정보가 불명확하거나 '확인 필요' 상태인 경우, 사용자에게 절대 "신청 가능합니다"라고 확답하지 말고 "공식 공고문에서 세부 요건 확인이 필요합니다"라고 명확히 안내하십시오.
3. 모든 정책 추천 답변의 끝에는 공식 근거 문서 ID(예: DOC_NHUF_008)와 공식 신청 URL을 인용하십시오.
```
