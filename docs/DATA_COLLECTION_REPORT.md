## 1. 개요 및 수집 목표

본 문서는 **SSOK** 서비스 구축을 위해 공식 출처로부터 수집한 지원정책 원문 데이터와 전처리 가공 내역, 품질 검증 결과를 기록한 독립 보고서입니다.

- **핵심 목표:**
  - 사용자 프로필(연령, 거주지, 혼인 여부, 취업 상태, 소득 수준)에 따른 맞춤형 정책 추천에 필요한 신뢰할 수 있는 공식 근거 확보.
  - 임의 생성이나 추측 데이터를 철저히 배제하고, 공공기관 공식 공고문 원형(PDF/HTML)을 다운로드하여 SHA256 해시로 무결성을 입증.
  - Graph DB(Neo4j)와 Vector DB(Qdrant)의 공통 인터페이스 계약(`policy_id`, `document_id`, `chunk_id`)을 준수하여 상호 연동 가능한 정제 데이터셋 구축.

## 4. 정제 및 가공 데이터 구조 (Processed)

가공된 데이터셋은 PRD 6장 스키마 및 코딩 스타일에 맞춰 `data/processed/`에 4종의 JSONL로 구축되었습니다.

| 파일명 | 용도 | 건수 | 설명 |
|---|---|---|---|
| `policies.jsonl` | Graph/규칙 엔진 | 10건 | 정책별 고유ID, 연령/지역/소득/혼인 규칙 및 접수상태 |
| `documents.jsonl` | Vector DB 원문 | 13건 | 원문 텍스트 전체, 출처 URL, 발행일, 해시값, 검수 상태 |
| `chunks.jsonl` | Vector 임베딩 | 63건 | 500~1,000자 단위 의미 청크 (페이지/문단 제목 보존) |
| `graph_edges.jsonl` | Neo4j 관계 적재 | 26건 | 정책-기관, 정책-대상, 정책-조건(AND/OR), 정책-정책(개정) 관계 |

## 6. 결측치, 예외 및 논리 처리 규칙

1. **상태값 분리 (`reception_status` vs `policy_status`):**
   - LH 26년 1차 공고(`POL_001`): 접수기간(2026.04.15~04.17)이 지났으므로 `reception_status: "closed"`로 기록하되, 신혼부부 임대주택의 공통 자격조건 및 필수 제출서류 근거를 위해 `historical` 레코드로 보존.
   - 주택도시기금 버팀목/디딤돌(`POL_003`, `POL_004`): 상시 신청 가능하므로 `reception_status: "active"`.
2. **소득 요건 예외 판정 (AND / OR 복합 조건):**
   - 2026-10-19 소득요건 합리화(`POL_002`)는 기존 `POL_003`의 조건을 대체(Overwrite)하는 것이 아니라, **"부부합산 소득이 기존 기준을 초과할 때 대출신청인 1인 소득이 기준액 이하인 경우에 한해 추가 자격을 부여"**하는 `OR (예외)` 구조임.
   - 단, 이 경우에도 **"대출신청인은 반드시 계약체결자(차주)여야 함(AND)"**, **"자산심사는 부부합산 기준(AND)"**이라는 엄격한 규칙을 `graph_edges.jsonl`에 명시함.
3. **결측값 원칙:**
   - 종료일이 정해지지 않은 상시 대출은 `application_end: null`로 기록.
   - 불명확한 수치나 자격은 `unknown`으로 기록하고 추측으로 채우지 않음.

## 7. 수집 재현 명령

모든 데이터는 아래 명령으로 언제든지 100% 동일하게 재수집 및 전처리될 수 있습니다.

```powershell
# 1. 의존성 설치
pip install -r requirements.txt

# 2. 공식 원본 파일 다운로드 및 무결성 검증 (SHA256)
python scripts/download_raw.py

# 3. 전처리 데이터셋 생성 (policies, documents, chunks, graph_edges, source_registry)
python scripts/build_processed_dataset.py --raw-dir data/raw
```
