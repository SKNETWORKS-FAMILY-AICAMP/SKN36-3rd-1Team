## 1. 개요

본 디렉터리는 SSOK 프로젝트의 데이터 수집, 정제, 릴리스 검증 과정에서 작성된 **9종의 품질 감사 및 릴리스 적합성 검증 보고서**를 보관합니다.  
공식 정부 원문과의 정합성, 신청 URL 유효성, 결함 수정 이력을 투명하게 추적할 수 있습니다.
