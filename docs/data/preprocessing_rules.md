# 전처리 규칙 (초안)

> 담당: 데이터 (장반석) · 상태: **초안**
> 근거: [PRD §4.1](../product/PRD.md), [CODING_STYLE §5](../development/CODING_STYLE.md)

## 1. 원본 보존

- 원본은 `data/raw/<provider>/`에 원형 그대로 저장하고 덮어쓰지 않는다.
- 파일별로 원본 URL, 수집 시각, HTTP 상태, 저장 경로, 해시를 기록한다.
- 다운로드 실패도 링크와 실패 원인을 기록한다.

## 2. 정제

- 인코딩 UTF-8, 날짜 ISO 8601, 시간대 `Asia/Seoul` 명시.
- HTML 메뉴·광고·반복 내비게이션 제거. 자격 예외·각주·표 행/열 관계·부정문·단위는 보존.
- PDF는 제목·소제목·문단·페이지 번호 보존. 스캔 이미지·표 추출 실패는 임의 보정하지 않고 검수 대상으로 분리.
- 원문에 없는 조건을 LLM 추측으로 채우지 않는다. 자동 추출 값은 근거 위치와 검수 상태를 함께 기록.
- 모르는 날짜·값은 추정하지 않고 `null` / `unknown`.

## 3. 중복·버전

- 안정적 ID와 콘텐츠 해시로 재수집 시 중복 추가를 막는다.
- 정책명이 같아도 연도·지역·공고가 다르면 별도 레코드.
- 정정공고가 있으면 최신판을 우선하고 이전 공고는 이력으로 보관.

## 4. 건수 기록

원본 건수 → 제외·중복 건수(사유 포함) → 최종 건수를 기록하고, 변환 실패 샘플을 남긴다 (산출물 01).
