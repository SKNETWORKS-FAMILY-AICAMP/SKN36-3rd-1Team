## 2. 4단계 상태(Status) 관리 체계

데이터 무결성과 검색 안정성을 유지하기 위해 모든 검토 대상 데이터에 4단계 상태 체계를 적용합니다.

1. **자동 검증 통과 (`auto_normalized_pass`, 70건):**
   - 연령제한여부(`sprtTrgtAgeLmtYn`)가 'N'이면서 0~0세로 기재된 건은 "연령 제한 없음"으로 안전하게 정규화(`min_age: null, max_age: null, age_limit: false`)하여 서비스 검색에 즉시 활용 가능.
2. **추가 확인 필요 (`needs_manual_check`, 1,003건):**
   - 연령제한여부가 'Y'이나 0~0세인 994건, 소득상한 0원 등 원문 공고문 대조가 필요한 레코드.
   - 검색 후보군에는 노출되되, 추천 엔진에서 "자격 확정"이 아닌 "공고문 확인 필요" 상태로 서빙.
3. **실제 오류 확인 (`actual_error_confirmed`, 8건):**
   - 최소연령이 최대연령보다 큰 경우(예: min 34세 ~ max 19세).
   - 추천 필터링에서 연령 자동 판별을 차단하고 텍스트 검색 모드로 격리.
4. **수동 검증 완료 (`manual_verified`, 21건 / 문서 30건):**
   - 공식 PDF/HTML 공고문 원문과 1:1 대조 및 수치 교정이 완료된 핵심 기준 데이터.

## 3. 통합 데이터셋(237건) 내 연령 검토 대상(28건) 조치 내역

통합 237건 정책 중 온통청년 원천에서 0~0세로 유입된 28건의 대표 정책(`POL_YC_001`, `POL_YC_003` 등)에 대해 다음과 같이 정규화를 완료했습니다:
- `requirements.min_age`: `null` (기존 0 제거)
- `requirements.max_age`: `null` (기존 0 제거)
- `requirements.age_limit_yn`: 원본 값 보존
- `requirements.age_review_needed`: `true`
- `eligibility`: `"연령: 미상 (원문 0~0세 표기 오류, 공고문 확인 필요) ..."`
- **효과:** 만 0세 유아에게 성인 인턴십이나 창업 정책이 추천되는 치명적 매칭 오류를 원천 차단함.
