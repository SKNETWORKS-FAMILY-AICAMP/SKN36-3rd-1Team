## 1. 개요

본 디렉터리는 수집·정제된 복지 정책 데이터셋의 **생애주기(Life Cycle)** 및 **대상자 속성(Target Attributes)** 분포 균형과 품질 개선 효과를 통계적으로 분석한 보고서를 보관합니다.
