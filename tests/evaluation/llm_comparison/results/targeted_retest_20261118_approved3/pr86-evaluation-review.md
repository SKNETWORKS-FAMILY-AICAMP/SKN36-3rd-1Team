## 평가 도구의 동작
- --execute 전에는 모델을 호출하지 않는다.
- --budget은 확인된 누적 추정 비용에 도달하면 다음 요청을 중단하는 기준이다. 마지막 요청의 초과를 막는 엄격한 청구액 상한이 아니다.
- 유한한 양수 예산만 허용한다. 비용 미확인 시 기록을 보존하고 다음 호출을 중단한다.
- 요청별 입력/출력/usage 체크포인트를 남기며 저장 실패를 완료로 표시하지 않는다.
- --resume-dir은 코드·질문·manifest·검색 프로필·가격의 동일성과 CSV/JSONL의 헤더·행 전체 일치를 확인한다. 완료 조합을 재호출하지 않고, 결과 행에 없는 SDK 시도는 수동 복구 전 재호출을 막는다.
- JSON 정규화와 마스킹 판정을 구분한다. 비밀값의 원문·URL 인코딩 형태를 마스킹한다.
- 기록을 위해 검색·LLM을 추가 호출하지 않는다.
