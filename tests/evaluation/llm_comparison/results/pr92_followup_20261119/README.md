## 실제 모델 평가와 저장 응답 재생

최신 데이터와 실제 DB가 불일치해 **유료 호출 전에 중단**했다. 사용자가 확인한 노션 작업 순서상 최신 데이터 재적재는 아직 진행 전이며, 현재 DB의 이전 버전은 예정된 상태다. 새 실제 mini 호출 0회·토큰 0·비용 $0이다. 기존 31건은 당시 증빙으로 그대로 보존했으며 이번 수정본의 실제 평가로 재분류하지 않았다.

사전에 제시한 후속 계획은 최대 14회(기존 5문항, RQ040/042 원질문 각 2회 추가, 유사 질문 각 2회, 정확히 60일 질문 1회), 추정 $0.04~0.07, 누적 비용 $0.10에서 다음 호출 중단, SDK 재시도 0회다. 마지막 요청의 비용 초과 가능성은 있다. `evaluation-plan.json`에 코드·프롬프트 해시와 실행 차단 사유·질문 목록을 기록했다. 기존 평가 도구를 사용할 계획이며 새로운 유료 평가를 완료했다고 표시하지 않는다.

대신 기존 최종 v2의 실제 검색·모델 출력 18건을 수정된 Pipeline·Checker·Generator에 재생했다. 각 요청에서 검색 mock 1회·생성 mock 1회이며 Checker는 정책별로 호출된다. 18건의 답변 본문이 보존됐다. 이는 저장 응답 재생이고 현재 DB 검색이나 새 실제 모델 호출이 아니다. `saved-output-replay.json`을 참고한다.

RQ031 첫 결론의 경계 유보 실패는 재생에서도 그대로이며 해결하지 않았다. 강조가 과했던 기존 응답도 그대로여서 해결로 표시하지 않는다. 원문 해석을 임의로 확정하거나 문자열 치환으로 가리지 않았다. 최신 코드의 새 모델 출력에서 두 문제가 개선됐는지는 미검증이다.

## 남은 실행 조건과 판단

**현재 단계의 코드 수정분은 dev 병합 가능으로 판단한다.** 필터 회귀는 재현→수정→자동 테스트→가상 브라우저 확인을 마쳤다. 이번 변경은 새 DB 필드·컬렉션·청킹·임베딩·Checker 규칙을 요구하지 않으며, 새 공유 상태나 DB 쓰기 경로도 추가하지 않았다. 예정된 최신 데이터 재적재를 코드 병합의 선행 조건으로 삼아야 할 구체적인 의존성은 발견하지 못했다.

코드 병합 가능과 최신 데이터 통합 검증 완료는 별개다. 후자는 민혁님 재적재 후 진행할 후속 작업으로 남긴다. RQ031 경계 안내 실패·일부 과도한 강조·과거 기록 누락을 해결됐다고 표현하거나 #82를 자동 종료하지 않는다. 새 데이터에서 답변 품질이 그대로 유지된다고 보장하지 않는다.

민혁님이 예정된 최신 데이터 재적재를 진행한 뒤 실제 적재한 커밋·manifest를 확인해야 한다. 이번 비교 대상은 `e764518`이며 재적재 시 더 최신 스냅샷을 사용하면 그 버전으로 다시 대조한다. Neo4j는 조건·정책 속성·문서·관계에 위 차이가 있고 제거 대상 그룹·관계도 있어 단순 추가 적재만으로 일치하지 않는다. Qdrant는 변경 5개·신규 1개와 대응 벡터를 새 스냅샷으로 검증해야 한다. 변경 payload의 문서 해시만 바꾸어 벡터를 최신으로 간주하면 안 된다. 공유 DB 갱신은 다른 사용자의 검색·판정·화면에 영향을 줄 수 있으며 이번 코드 수정에서 수행하지 않았다.

민혁님 재적재 후에는 ① 읽기 전용 ID·속성·관계·payload 대조 ② 프로필/모델/차원 확인 ③ 위 14건 평가 및 별도 결과 저장 ④ 호출·인용 형식·핵심 의미 분리 판정 ⑤ 실제 화면 대조 순서로 이어간다. 그때의 코드·프롬프트·실제 DB 버전을 새 기록에 함께 고정한다. 이번에는 공유 DB를 우회·변경하지 않았다.
