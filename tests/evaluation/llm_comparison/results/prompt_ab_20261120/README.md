- 지침 A(경계 충돌): 기존 "충돌 범위는 확정할 수 없다"에 더해, 경계값에서 결론이 갈리면 첫 문장에서 확정할 수 없다고 밝히고 '이상'·'이하'는 그 값을 포함한다는 규칙과 예시를 넣었다. 예시는 평가 문항(60일)과 다른 숫자(34세)를 써서 평가에 맞춘 문구가 되지 않게 했다.
